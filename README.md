# ScreenShareWiFi

اپ اندروید Kotlin برای اشتراک صفحه از طریق Wi‑Fi/LAN.

## اجرا
1. پروژه را در GitHub قرار دهید.
2. در Actions، workflow با نام **Build APK** را اجرا کنید.
3. فایل `app-debug.apk` را از Artifacts دریافت و روی گوشی نصب کنید.
4. برنامه را باز کنید و **شروع اشتراک صفحه** را بزنید و اجازه Screen Capture را تأیید کنید.
5. از دستگاهی که به همان شبکه Wi‑Fi وصل است، آدرس نمایش‌داده‌شده مثل `http://192.168.1.10:8080` را باز کنید.

## نکات
- برنامه از `MediaProjection` استفاده می‌کند و برای ادامه کار در پس‌زمینه یک Foreground Service اجرا می‌کند.
- با بستن Activity/خارج‌شدن از صفحه برنامه، سرویس فعال می‌ماند. اگر سیستم عامل سرویس را به‌دلیل فشار حافظه یا تنظیمات باتری کاملاً kill کند، ممکن است نیاز به شروع دوباره باشد.
- این نسخه احراز هویت ندارد؛ هر دستگاهی که به پورت 8080 دسترسی شبکه‌ای داشته باشد می‌تواند تصویر را ببیند. برای استفاده خارج از LAN یا Port Forwarding، حتماً احراز هویت/TLS اضافه کنید.
- کیفیت و FPS عمداً متوسط نگه داشته شده تا مصرف CPU، RAM و شبکه محدود شود.
